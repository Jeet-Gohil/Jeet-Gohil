### 2. State-of-Charge Estimation of Lithium-Ion Batteries
**Embedded C | STM32F407 | L9963E | MATLAB | Extended Kalman Filter**

- Implemented Coulomb Counting and Extended Kalman Filter algorithms for battery state estimation.
- Integrated current-based prediction with voltage-based correction using an OCV-SOC lookup table.
- Analysed the effects of noise covariance, initial conditions and battery-model accuracy on estimation reliability.
